Código C++ para ESP32

Servidor Web HTTP básico para la placa ESP32 (Compatible con Arduino IDE y VS Code)

#include <WiFi.h>
#include <WebServer.h>

// === Configuración de Red WiFi ===
const char* ssid = "TU_NOMBRE_DE_WIFI";      // Nombre de tu red WiFi
const char* password = "TU_CONTRASEÑA";       // Contraseña de tu red WiFi

// Servidor Web escuchando en el puerto 80
WebServer server(80);

// Pin del LED incorporado (En la mayoría de ESP32 es el GPIO 2)
const int ledPin = 2;

void setup() {
  Serial.begin(115200);
  pinMode(ledPin, OUTPUT);
  digitalWrite(ledPin, LOW); // Iniciar apagado

  // Conexión a la red WiFi
  Serial.print("Conectando a ");
  Serial.println(ssid);
  WiFi.begin(ssid, password);

  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }

  Serial.println("");
  Serial.println("¡Conectado exitosamente a la red WiFi!");
  Serial.print("Dirección IP asignada: ");
  Serial.println(WiFi.localIP());

  // Configuración de Rutas Endpoints
  server.on("/led/on", []() {
    digitalWrite(ledPin, HIGH);
    server.send(200, "text/plain", "LED ENCENDIDO");
  });

  server.on("/led/off", []() {
    digitalWrite(ledPin, LOW);
    server.send(200, "text/plain", "LED APAGADO");
  });

  server.on("/led/toggle", []() {
    int currentState = digitalRead(ledPin);
    digitalWrite(ledPin, !currentState);
    server.send(200, "text/plain", !currentState ? "LED ENCENDIDO" : "LED APAGADO");
  });

  // Iniciar Servidor
  server.begin();
  Serial.println("Servidor Web iniciado.");
}

void loop() {
  server.handleClient(); // Procesar solicitudes entrantes
}

Guía: Cómo subir el código usando Visual Studio Code

Sigue estos sencillos pasos para programar tu placa ESP32 utilizando la extensión **PlatformIO** o **Arduino** en VS Code.

1

Instalar VS Code & Extensiones

Abre VS Code y navega a la sección de extensiones (Ctrl+Shift+X). Busca e instala PlatformIO IDE o Arduino.

2

Configurar Credenciales WiFi

Copia el código C++ provisto arriba. Reemplaza "TU_NOMBRE_DE_WIFI" y "TU_CONTRASEÑA" con las credenciales de tu red WiFi local (2.4 GHz).

3

Conectar y Subir

Conecta el ESP32 a la PC con cable USB. Haz clic en el ícono de flecha (Upload) en la barra inferior de PlatformIO para compilar y cargar.

4

Obtener IP & Controlar

Abre el Monitor Serie (Baud rate: 115200). Copia la dirección IP mostrada (ej. 192.168.1.50) e ingrésala en el panel superior de este sitio web.

¿Problemas al subir el código? Si el monitor muestra "Connecting......", mantén presionado el botón BOOT en tu placa ESP32 durante el proceso de carga hasta que comience el grabado de la memoria flash.
